# territories

Every territory: country and state, its reps, professionals, A-segment count, how many are behind target and calls this cycle.

Run `node scripts/crm.mjs territories`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
