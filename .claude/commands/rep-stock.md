# rep-stock

Sample stock with each rep by lot (or --rep): on hand, expiry, and whether it is good, short-dated, expired or recalled.

Run `node scripts/crm.mjs rep-stock`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
