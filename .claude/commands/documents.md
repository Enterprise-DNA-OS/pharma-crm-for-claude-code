# documents

Render the starter pack request and delivery records, each rep's sample stock statement and the event records as branded HTML in docs-out/.

Run `npm run docs` (or `npm run docs -- <document> <id-prefix>`). The documents are records; print to PDF from the browser when one is asked for.
