# calls

Calls in the last 30 days (or --days=N, --rep, --hcp): who, products detailed, next step.

Run `node scripts/crm.mjs calls`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
