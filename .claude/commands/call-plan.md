# call-plan

The week's call plan for a territory or a rep (--territory or --rep, --days=7): professionals behind target, follow-ups falling due, starter packs to deliver and events coming.

Run `node scripts/crm.mjs call-plan --territory=<territory>`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Present it as the rep's week: who to see first and why. A-segment first, then follow-ups that are overdue.
