# account

One practice or hospital and every professional who works there, with segment and calls this cycle.

Run `node scripts/crm.mjs account <account>`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
