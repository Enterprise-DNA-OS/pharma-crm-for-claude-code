# draft-follow-up

Draft the follow-up email to a professional after a call, from the call's next step. Written to drafts/, never sent. Refuses anyone who asked not to be contacted.

Run `node scripts/crm.mjs draft-follow-up <call>`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Use approved materials only. Never add a product claim.
