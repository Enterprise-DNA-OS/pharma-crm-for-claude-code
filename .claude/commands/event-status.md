# event-status

Record an event as held or cancelled (--status), with the actual food and drink a head (--meal). Shows any Code issue it creates.

Run `node scripts/crm.mjs event-status <event> --status=held --meal=<amount>`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Every write needs `--actor="<your name>"`. Record the real figure even when it is over the cap: the record stays true and the breach shows.
