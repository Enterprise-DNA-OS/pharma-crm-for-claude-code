# add-territory

Add a territory: --code, --name, --country (NZ, AU), --state for Australia.

Run `node scripts/crm.mjs add-territory --code=<code> --name="<name>" --country=<NZ|AU>`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Every write needs `--actor="<your name>"`.
