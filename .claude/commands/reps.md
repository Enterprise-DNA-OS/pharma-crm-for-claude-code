# reps

Every rep: territory, sample licence and when it runs out, calls this cycle and sample units held.

Run `node scripts/crm.mjs reps`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
