# weekly-review

Write the Monday field review to drafts/: what needs a person, coverage this cycle and open follow-ups.

Run `node scripts/crm.mjs weekly-review`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
