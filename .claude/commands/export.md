# export

Export every record to one JSON file the business owns. It holds personal information about health professionals: keep it as securely as the database.

Run `node scripts/crm.mjs export`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
