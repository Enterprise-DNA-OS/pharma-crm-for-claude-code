# attention

Show what needs a person today: Code breaches, recalls not finished, reviews and reports due, starter packs waiting, rep licences running out, short-dated stock, overdue follow-ups, A-segment professionals not seen this cycle, and events with attendance not recorded.

Run `node scripts/crm.mjs attention`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Lead with breaches and name the section. Suggest the one next step for each line (usually /recall-told, /move-stock, /sign-receipt, /send-review, /submit-report, /deliver-sample, /follow-up-done or /call-plan).
