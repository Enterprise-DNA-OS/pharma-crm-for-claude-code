# declare-report

Record the company declaration lodged after a submission (--period, --date). Shows whether it was within seven days.

Run `node scripts/crm.mjs declare-report --period=<H1-2026>`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Every write needs `--actor="<your name>"`.
