# settings

The house rules: call cycle, short-dated days, starter pack delivery days, quiet days, licence warning days and the Australian hospitality cap.

Run `node scripts/crm.mjs settings`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
