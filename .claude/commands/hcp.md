# hcp

One healthcare professional in full: where they work, segment, the last ten calls, starter packs, events and every transfer of value. Find them by code, name, surname or registration number.

Run `node scripts/crm.mjs hcp <professional>`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
