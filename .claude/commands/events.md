# events

Every event (or --upcoming): kind, country, date, food and drink a head, invited and attended.

Run `node scripts/crm.mjs events`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
