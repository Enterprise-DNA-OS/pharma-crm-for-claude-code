# hcps

Every active healthcare professional (or --territory, --segment=A, --specialty, --all for retired and moved): target calls, calls this cycle, last call.

Run `node scripts/crm.mjs hcps`. Add `--json` when you need every field. Resolve the professional, practice, rep, lot, sample, event or territory by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
